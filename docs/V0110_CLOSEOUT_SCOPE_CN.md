# 0.11.0 有限收尾范围

本版完成工程接入，首篇稿件的软件功能进入冻结候选状态。上一版通用测试范围不继续扩大，RUN24 的跨地形结果保持原证据身份。

## 当前交付

冻结内核的 GUI 与处理接入、四方法比较、项目和报告互操作；旧实现的限制提示；明确的本地代码启动；一次有限用户端验收入口。原质量屏蔽、DoD 符号“后期减前期”、点位与区域保存、共同支持和网络规则保持原定义。

适配器先检查最大搜索范围内的有限移动 DEM 支持，排除不足 0.5° 的参考梯度，再按固定种子选取最多 12,000 个可用像元。适配器与 RUN24 的掩膜生成属于不同上下文，方法元数据分别记录冻结内核与外层选择。本版不将任意真实输入宣称为与 RUN24 完全相同的实验。

## 用户端验收结束条件

软件检查通过；GUI 正常打开，标题为 0.11.0；新方法可见且可保存/重开项目；结果与案例报告可见。Qt 平台、截图和用户视觉反馈分别记录。只有实际报错或证据不一致才修复对应事项；不再要求新种子、新地形或新算法的一般性测试。

验收入口使用既有三期模拟 DEM 验证接入，四方法报告使用其中两期。它不是新的真实案例、外部测高或方法排名研究。GUI 默认首次选择仍为 Raw DoD；比较模式的初始显示是固定显示策略。

## 首篇论文剩余交付

1. **一个真实主案例证据表。** 优先 Barry Arm 现有输入：日期、源影像、坐标/垂直参照；经审阅固定的目标、稳定拟合与留出对象；同支持方法结果和固定点；外部参照与时间/来源局限。未审阅稳定区不投入真实科学配准。
2. **完整稿件和图表。** 已有工作流、受控方法、RUN24 结果和讨论现在推进；真实案例完成后补入结果。对成熟方法正确归属，受控参数误差不写成实际 ArcticDEM 精度。
3. **复现与投稿材料。** 固定源码、对象、配置、图表来源、依赖和说明；公开代码的许可证、仓库和存档标识在投稿前确定。当前包不作出新的公开授权或数据再分发承诺。

其他地貌主案例、全 ArcticDEM 覆盖、ICP、非刚性方法与空间协方差不确定性不作为当前软件稿件的前置条件。真实主案例按固定输入如实报告，不以误差必须改善为停止条件。
