# 共同验证范围上的误差结构

0.9.0 将方法比较从全区单一 NMAD 扩展到地形条件与空间分布。需要回答的是：不同方法在相同像元上是否仍有系统偏差，哪些地形条件下残差较大，以及全区统计是否掩盖了局部正负偏差。

本模块读取已经保存的高程栈，不重新配准、不修改原始 DEM，也不利用待评估残差重新挑选稳定区。残差解释以用户提供的验证地形确实稳定为前提。

## 在界面中使用

1. 在 `6 Case project` 打开已保存的案例，确认结果目录、固定 ID 的采样点和 `target` 区域。旧项目不要重新绘制另一套点和边界。
2. 若已有三方法比较结果，选择该比较的父目录；若只有单方法结果，也可导出，但报告会标明单方法诊断。
3. 点击该页的报告导出按钮，选择一个新的输出文件夹。导出完成后点击 `Open report`。
4. 查看 `Shared support`、`Comparison conditions` 和地形/空间块表；详细数值保存在 `common_support` 子目录。用 `Show common support` 查看实际质量有效交集。

结果目录必须包含完整的已保存高程栈、质量/拟合/验证掩膜和来源记录。轻量上传 ZIP 省略了大型栅格，通常不能直接用于重新计算这些诊断。

## 最简本机验收

在已正常工作的环境中，进入本版目录，运行：

```bat
RUN_07_REPORT_DIAGNOSTICS_DEMO.bat
```

程序生成四期合成 DEM，运行三种配准方法，对同一个目标区和固定点导出报告，并检查预设 −12 m 变化是否保留。控制台给出 `REPORT:` 和 `UPLOAD ZIP:` 路径。该 ZIP 适合回传诊断；模拟结果不能证明实际 ArcticDEM 精度。

已有结果可用以下命令导出，替换示例路径即可。`--objects` 可以省略；省略后不生成用户自定义目标区或点统计。

```bat
python tools\run_report_diagnostics.py --results "C:\DoDArcticDEM\MyCase\results\comparison_001" --objects "C:\DoDArcticDEM\MyCase\objects.geojson" --workspace "C:\DoDArcticDEM\MyCase"
```

这个入口只读取 `--results` 中的已完成数据，并在工作区新建带时间戳的诊断文件夹。若需要重新配准，应在界面的分析页建立新的科学运行。

## 比较条件如何检查

共同支持模块先核对栅格网格、时相 ID、日期、数据来源校验及分析域。随后形成所有纳入方法、所有时相均有效的像元交集。验证区进一步取各方法保存的验证候选区交集，并排除任何方法的保存拟合区。

`comparison_contract.json` 记录这个事后核查的结果；它不是预注册证明，也不证明外部数据独立性。数值设置中的 `2` 和 `2.0` 按相同参数处理；省略参数按软件有效默认值解释。

| 状态 | 含义 | 后续动作 |
|---|---|---|
| `controlled_internal_comparison` | 已保存且可核查的比较条件一致，具有最低内部验证支持 | 继续检查地形、空间分布、参数合理性及外部证据 |
| `descriptive_only` | 单方法、请求的方法缺失、候选区/参数/版本差异，或验证支持不足等 | 阅读 `issues`；明确比较对象，必要时按统一配置新建运行 |
| 共同支持不可用 | 输入、网格或必需文件不能满足共同统计条件 | 补齐原始运行资料；保留不可用原因 |

即使候选拟合掩膜一致，各算法实际保留的拟合样本也可能不同。这里固定的是评估像元；不能把它描述成各算法拥有完全相同的最终拟合样本。

## 地形分层规则

地形分类使用所有纳入方法内容一致的首期参考栈。若首期值不同，跳过地形分层并写明原因；共同支持和空间块统计仍可作为描述性诊断。

| 属性 | 分类方式 | 必须保留的说明 |
|---|---|---|
| 坡度 | 0–2、2–5、5–15、15–30、30–45、45–90 度 | 左闭右开，末组含 90 度；EPSG:3413 使用局地投影尺度修正，其他投影明确标记为地图坐标坡度近似 |
| 坡向 | 投影网格北起顺时针的八方向 | `grid_N` 等代表网格方向，不是地理真北；坡度小于 2 度单列为平地 |
| 参考高程 | 共同验证像元首期高程的四分位切点 | 重复切点合并，等于切点归上组，保留空组；不同案例切点可不同 |
| 属性缺失 | `unavailable` | 保留边界和空洞邻近像元，不能让它们静默消失 |

导数使用中心像元及四个相邻像元，边界不做单侧补算，也不填空洞。每一种属性的各组相加都等于相同的共同验证像元数；不能把坡度组、坡向组和高程组相加成样本总数。

每组包含 n、中位数、NMAD、RMSE、MAE 和所占空间块数。少于 64 个像元或 3 个占用块标记为 `limited_support`，空组保留缺测值。这是报告支持度阈值，不是显著性判据。

## 空间块及方法差值

以输出网格左上角为固定原点，按保存的验证块边长 B、2B、4B 汇总同一批像元。若各运行 B 不同，诊断取最大 B，同时比较条件标为不一致。边缘块记录实际宽度和高度，块中心为矩形中心，未假设有效像元填满整个块。

逐块表保留少于 16 个像元的稀疏块。尺度汇总对占用块的中位数等权统计最小、最大及第 5/95 百分位；不同尺度重复使用相同像元，不能作为独立重复。逐块行数超过 150,000 时跳过本模块并给出原因，共同覆盖与区域统计仍保留。

方法差值固定定义为指标(B)−指标(A)。RMSE/NMAD 的负值表示 B 的该项描述性指标较小；有符号中位数的负差值只表示偏差方向变化，不代表更接近零。所有差值均不是显著性检验，不能单独触发自动方法择优。

| 文件 | 用途 |
|---|---|
| `comparison_contract.json` | 比较条件、例外、版本、掩膜校验与内容摘要 |
| `terrain_definition.json` | 地形分类规则、切点、参考值与分类成员校验 |
| `terrain_validation_statistics.csv` | 所有方法、时段和地形组的共同像元残差 |
| `validation_spatial_blocks.csv` | 逐方法、时段、尺度和空间块的残差；含投影坐标，可在 GIS 中定位 |
| `block_scale_summary.csv` | 各尺度的块数、像元数及块中位数分布 |
| `matched_support_metric_differences.csv` | 相同支持下的 B−A 指标差值 |

## 与不确定度模型的关系

地形分层与空间结构检查是进一步建模的依据。稳定地形上的异方差、空间相关及其向目标区域迁移的条件需要分别处理，才能合理传播区域量的不确定度；这也是 [xDEM 官方空间误差分析说明](https://xdem.readthedocs.io/en/stable/spatial_stats.html) 强调的步骤。

本版没有拟合变异函数，没有估计有效独立样本量，也没有输出 LoD95 或体积置信区间。空间块中位数的 5–95% 范围仅描述块间差异。这里的诊断由本软件独立实现，不能写成已经调用或通过 xDEM 验证。
