大片区域有 2016/2018 两期支持；2022 年的可用范围使三期共同支持集中在东侧。因此，检索到多期资料不能直接推出整个 AOI 都能开展同样的时序研究。比较二期、三期或不同方法时，应固定评价区域，或者明确报告支持范围的差别。

缺测保持缺测。缩小 AOI 会改变研究范围和面积分母，不能单纯为了提高覆盖比例而缩小科学目标。应先核对目标边界，再记录它的实际被观测部分。

## 证据和复现

本次完整检查归档于 `validation/v0100/batagay/pilot_20260929_124212_603878/`。其中 `coverage/report.html` 可直接打开；JSON、CSV、覆盖栅格和哈希记录可逐项核查。`acceptance.json` 明确记载真实数据来源、`registration_performed=false` 和 `field_accuracy_validated=false`。

原始三期裁剪另存为 `ArcticDEM_Batagay_Pilot_Inputs_20260929.zip`，使用相对路径清单、源条带元数据和文件校验值。它可以配合本版进行离线复现；联网运行同样可按固定 ID 重新获取。使用方法见 [覆盖操作说明](PRE_REGISTRATION_COVERAGE_CN.md)。发布包归档报告中的开发机绝对路径只是来源记录，本机项目应由脚本重新生成。

下一步先导入有依据的真实目标区，判断三期交集是否包含关键变化部位；再结合可靠影像或独立成果确定稳定拟合区、分离验证区和固定采样点。之后在相同输入及共同支持上比较三种配准方法，并统一文献时段、范围、基准与测量量。

本次结果没有确定高程准确度、滑塌体积、融冰量或碳通量。PGC 产品说明见 [ArcticDEM 官方资料](https://www.pgc.umn.edu/data/arcticdem/)，数据引用为 [ArcticDEM Strips Version 4.1](https://doi.org/10.7910/DVN/C98DVS)。Batagay 文献起点与来源解释见 [已发表案例说明](PUBLISHED_CASES_CN.md)。
