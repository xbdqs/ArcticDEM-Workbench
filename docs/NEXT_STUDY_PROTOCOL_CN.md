## 第一个主案例：Batagay 热融滑塌

已有模板以 Kizyakov et al. (2024) 为文献起点，具体来源和检索范围见 [已发表案例说明](PUBLISHED_CASES_CN.md)。模板范围用于初始检索，不能代替论文的精确目标边界。

先检索 2—3 个独立日期，核查季节、影像配对及质量掩膜，形成同一区域的有效覆盖。核心观测量设为固定目标区的地表高差、实际观测面积和几何体积变化。优先完整描述可观测部分，缺测区域保持缺测。

参考资料获取清楚后，再确定能否进行与论文的数值对比。参照量须记录 DOI、页码/图表、时段、几何边界、垂直基准、单位、数据来源以及是否共享影像。共享 ArcticDEM 资料的结果只能提供相关的实现/方法对照，不能当作独立地面真值。

在查看最终方法排名之前保存一份案例决策表，至少包括以下项目；已有结果应如实标为探索性分析，不补写成预注册。

| 决策项 | 要固定的内容 |
|---|---|
| 科学问题 | 要比较的地表高差/几何体积及其空间、时间范围 |
| 输入与时相 | 每期条带 ID、成像日期、处理版本、文件校验；同日和共享源影像处理规则 |
| 空间对象 | AOI、目标区、样点固定 ID 及导出 GeoJSON；跨方法保持坐标相同 |
| 拟合与评估 | 独立知识支持的稳定区、留出区、空间分离和坡度/坡向覆盖 |
| 运行条件 | 分辨率、质量掩膜、三种方法、最大位移、配对网络、验证块尺寸 |
| 主要结果 | 固定共同支持的高差和体积、目标区有效面积；不只保留最小残差 |
| 失败与偏离 | 缺少覆盖、参考不足、方法拒绝、参数改变及改变原因 |
| 外部参照 | 与本研究的可比关系及尚未解决的差异 |

一套运行完成后，用 0.9.0 报告同时检查全区偏差、地形组差异和空间块残差。若使用留出区选择方法，该区域便参与了模型选择；最终精度声明须依赖另一个未参与选择的测试集。稳定区不足时，应先改变资料范围或补充参考证据，不为贴近文献数值反复重画稳定区。

## 后续案例分别验证什么

| 案例 | 与主案例不同的测试条件 | 需要控制的关键问题 |
|---|---|---|
| Karrat 岩质滑坡 | 大变化、陡坡、事件前后观测和缺测 | 区分滑源/陆上堆积/不可见区域；用实际 DEM 日期界定观测间隔 |
| Vavilov 冰盖 | 运动表面、多期观测及冰外参考 | 寻找可靠冰外稳定地形；固定地图像元高程与沿冰体运动轨迹的变化分别解释 |
| 石冰川或海岸侵蚀（候选） | 更慢变化或细长变化带 | 只有覆盖、稳定参考、独立数据和时间尺度适合时再加入 |

Karrat 文献同时涉及 2016 年和 2017 年事件，并讨论 ArcticDEM 灾后缺测，不能将跨越两次事件的差分都归到 2017 年。[Svennevig et al. (2020)](https://esurf.copernicus.org/articles/8/1021/2020/)。冰川案例的参照文献与研究窗口见既有 [案例说明](PUBLISHED_CASES_CN.md)；固定像元的高差也不能单独解释为局地消融或整个冰盖的质量变化。

## 算法与论文的推进顺序

当前基线为 vertical、稳健三参数平移和 Nuth–Kääb。用户提出的 [demcoreg](https://github.com/dshean/demcoreg) 可作为配准流程与其他后端的参考。新方法应在统一数据接口、变换方向、掩膜、失败条件和保存格式下实现与验证；名称相同不保证具体采样、优化及停止条件相同。

当实际案例显示三参数模型存在残余结构时，再判断其来源。首先排查稳定区、雪、匹配空洞、方向与基准；只有证据支持模型不足，才比较旋转、平面趋势、分块或其他模型。高自由度模型需要检查真实变化是否被吸收，不能只以拟合残差更小作为采用依据。

论文首先组织一篇软件与验证论文：可追溯查询下载、固定对象、共同像元方法比较、已知真值验证、明确失败行为及实际案例。方法改进论文需要额外提出并检验明确的新假设；不同地貌应用论文应有自己的过程问题和独立数据，不机械地按对象拆分相同流程。

区域误差传播可作为后续独立开发单元，先验证误差随地形变化、空间相关及稳定区向目标区迁移的适用条件，再估计区域量的不确定度。闭环继续作为配准网络一致性诊断；由同一组高程直接作差得到的代数闭合不增加独立精度证据。
