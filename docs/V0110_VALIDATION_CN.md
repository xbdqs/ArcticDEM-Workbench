## 证据范围

本版不重新运行 RUN24，不扩大地形迁移实验。RUN24 中联合梯度方法的 36/36 参数检查与 8/8 人为变化检查继续归属原受控试验。冻结内核与生产适配器的支持选择分别记录；真实 DEM 的外部精度需要真实参照数据与审阅后的空间设计。

三期模拟工程验收检查方法是否正确接入处理、网络和报告。共同支持、低残差、优化收敛或闭环一致均不能单独确认实际高程准确度。此版本不增加“实际 ArcticDEM 厘米级精度”的论断。

## 一次用户端验收及停止条件

在原有 `arcticdem_dod` 环境运行 `RUN_PAPER_RELEASE.bat`。脚本不安装包、不下载数据，在新验收子目录内生成结果；在创建 Qt GUI 前保存诊断 ZIP。查看 0.11.0 标题、新方法列表、模拟结果和共同范围报告，关闭 GUI 后上传控制台最后显示的 ZIP，并说明这些界面是否正常。

软件检查及 Windows 显示通过后，冻结当前功能并进入真实主案例与稿件整理。若发现启动、计算、项目恢复或报告的具体阻断错误，修复对应问题；不追加新种子、新地形或新算法的一般性验收。真实主案例按固定输入如实报告，停止条件不要求新方法必须优于全部基线。

保留旧 0.10.1 文件夹及其研究入口。带旧版哈希/版本约束的历史脚本继续在旧目录使用，其版本拒绝检查属于历史复现保护。本版用户验收统一使用新入口。
