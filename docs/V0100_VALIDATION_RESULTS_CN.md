# 0.10.0 验证记录

验证日期：2026-09-29。基线恢复自正式保存的 0.9.0 发布包，在独立目录实现覆盖检查并重新验证。旧版本和用户 Windows 环境没有被修改。

环境为 Linux / Python 3.12.14 / Qt offscreen。主要依赖为 NumPy 2.2.6、SciPy 1.15.3、Rasterio 1.4.4、GDAL 3.10.3、PyProj 3.7.2、Shapely 2.1.2、Matplotlib 3.10.8、PySide6-Essentials 6.9.3。这些结果不能代替 Windows 实机验收。

## 回归与合成集成检查

`tools/validate_release.py` 运行 **79 项测试，全部通过**，耗时约 19.2 秒。证据保存在 `validation/v0100/regression/tests.log` 与 `verification.json`。这包括原有 69 项以及 10 项新增覆盖、完整性和 GUI 项目检查。

覆盖测试核对地面面积权重、日期对与三期支持差异、缺测时间跨度、重复日期拒绝、原生质量掩膜、验证区优先及两像元缓冲、输入变化、取消状态、冻结选择和项目恢复。覆盖功能不调用配准估计器。

四时相合成流程完成三方法比较、固定点/区域报告和项目重开：

| 方法 | 目标区首末期平均高差（m） | 设定真值（m） |
|---|---:|---:|
| vertical | −11.999360 | −12 |
| translation | −12.000096 | −12 |
| nuth_kaab | −11.999099 | −12 |

最终共同支持 64,256 像元，共同验证支持 10,523 像元，固定点导出 24 条记录。以上数字是受控合成检查，不能解释为真实 ArcticDEM 的精度。

## 真实数据与界面

Batagay 三期 DEM 与两类质量掩膜均成功下载，共九份栅格，输入在覆盖检查前后哈希一致。实测至少两期有效覆盖 99.9832%，三期共同有效覆盖 39.8657%；完整数字见 [Batagay 记录](BATAGAY_PILOT_RESULTS_CN.md)。该检查不包含真实配准和外部准确度验证。

`validation/v0100/coverage_gui` 保存真实项目恢复、控制区、日期数量图、全部日期交集与 2018/2022 交集的截图。项目恢复无缺失路径警告，离屏查看器通过，保留左键拖动、滚轮缩放和导出入口。

三期输入另以相对路径整理后移到新目录，使用 `--clips` 离线重跑。单期、逐对和全时相统计完全一致，四份覆盖栅格 SHA-256 均相同。证据为 `validation/v0100/offline_relocation.json` 及相应日志。Windows BAT 会在代码目录检测 `Batagay_Pilot_Inputs/epochs.json`，存在时采用同一离线入口。

## 归档与限制

源码比较确认 `coreg.py`、`network.py`、`raster.py`、`requirements.txt` 与正式 0.9.0 基线一致。本版增加检查模块及界面/项目连接，没有新增配准后端或改变估计器。

旧 `validation/v080`、`validation/v090` 及更早目录按版本保留历史证据。此前 48 组/192 条扩展实验没有在本轮重跑，不计为新的真实案例或独立验证。xDEM 外部比较恢复仍需用户侧成功材料。

打包保留所有输入选择与证据文件的原始字节，避免重新格式化 JSON 或修改路径后破坏嵌套哈希。发布清单逐文件记录 SHA-256，构建器通过 ZIP CRC 和清单核验后才输出正式 ZIP。归档的开发机绝对路径用于追溯，Windows 使用提供脚本生成本机路径。

剩余用户验收为：启动 0.10.0、运行 Batagay 脚本、打开本机项目及覆盖查看器，然后回传脚本生成的诊断 ZIP。
